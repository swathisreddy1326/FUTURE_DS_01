# Task 1: Business Sales Performance Analytics

## Objective
Analyze business sales data to identify revenue trends, top-selling products, high-value categories, and regional performance.

## Tools Used
- Power BI
- MS Excel

## Key Insights
- Technology category contributes the highest sales.
- Sales show an increasing trend over the years.
- West and East regions generate maximum revenue.
- Phones and Chairs are top-selling sub-categories.

## Deliverables
- Interactive Power BI dashboard
- Key business insights and visualizations
