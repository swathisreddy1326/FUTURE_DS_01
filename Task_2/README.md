# Task 2: Customer Retention & Churn Analysis

## Objective
Analyze customer data to identify churn patterns, key retention drivers, and customer lifetime trends for a subscription-based business.

## Tools Used
- Power BI
- MS Excel

## Key Metrics
- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate (%)

## Key Insights
- Month-to-month contract customers show the highest churn.
- Churn is higher among customers with shorter tenure.
- Electronic check payment users churn more frequently.
- Retained customers significantly outnumber churned customers.

## Recommendations
- Encourage customers to switch to long-term contracts.
- Improve onboarding experience for new customers.
- Provide incentives for auto-payment methods.

## Deliverables
- Interactive churn analysis dashboard
- Actionable insights to reduce customer churn
